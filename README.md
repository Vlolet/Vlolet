### 1. 🎧 위험 소리 감지 및 알림 앱 (Qualcomm 연계 프로젝트)
*   **Role:** 모델 학습, 퀄컴 칩 활용 최적화, 앱 구현
*   **Description:** 주변의 위험 소리를 감지하여 사용자에게 알림을 주는 애플리케이션 개발. 무거운 딥러닝 모델을 엣지 디바이스(Galaxy S25 - Qualcomm Chip) 환경에서 빠르고 가볍게 동작할 수 있도록 최적화하는 과정을 주도했습니다.

### 2. 🚗 라즈베리파이 기반 홈서버 통신 자율주행
*   **Role:** 모델 구현, 홈서버 구축, 통신 및 주행 알고리즘 개발
*   **Description:** Raspberry Pi 4와 개인 구축 홈서버 간의 실시간 통신 아키텍처를 설계하고, 이를 기반으로 자율주행 알고리즘을 구현한 프로젝트입니다. 엣지 디바이스와 서버 간의 데이터 처리 역할을 성공적으로 분배했습니다.

### 3. ⚽ RoboCup LightWeight 축구 로봇 개발
*   **Role:** 하드웨어 제작(1년차) 및 소프트웨어 총괄(2년차)
*   **Description:** C 기반으로 로봇의 모터를 제어하고 센서 데이터를 처리하여 자율적으로 축구를 하는 로봇을 개발했습니다. 지속적인 알고리즘 고도화를 통해 2년 연속 '한국창의코딩대회 연구일지상'을 수상했습니다.

### 🖥️ Personal Infrastructure

> 개인적인 학습과 서비스 배포를 위해 홈랩(Homelab) 인프라를 직접 구축하여 운영 중입니다. 

- **Environment**: Oracle Cloud Infrastructure (OCI) ARM Instance
- **Containerization**: `Docker` 기반 서비스 환경 구축
- **Networking & Security**: `Cloudflare` 와 `Nginx Proxy Manager` 를 연동한 도메인 라우팅 및 SSL 인증서 관리
- **Monitoring**: 실시간 시스템 리소스(CPU, MEM, RX/TX) 모니터링 환경 구축
